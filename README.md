# Oluwatoyin Ijasanmi — COS 106 Portfolio

## Pages
- `index.html`: Home
- `about.html`: Education, skills, hobbies, and certificates
- `projects.html`: Three project descriptions, including the triangle and palindrome programs
- `planner.html`: Interactive task planner
- `contact.html`: Contact form with JavaScript validation

## Folder structure
- `css/style.css` — shared responsive design
- `js/site.js` — mobile navigation, current year, copy buttons
- `js/planner.js` — add, complete, delete, filter and persist tasks
- `js/contact.js` — validates required fields, email, and digits-only phone
- `assets/` — profile photograph, certificate files, certificate preview, and SVG illustrations

## Run it
Extract the ZIP, open the folder in VS Code, and open `index.html` in a browser. You can also use the Live Server extension.

## Before submission
1. Replace `assets/profile-placeholder.svg` with your own photograph and update the image paths in `index.html` and `about.html`.
2. Check every detail and add certificate details if you want to show them.
3. Compare the sample Python code with your original COS 102 programs.
4. Test every page and test the planner and contact validation.
5. The planner uses browser localStorage and does not sync across devices.
6. The contact form validates only; it does not deliver messages until connected to a backend or form service.

## GitHub Pages
Create a GitHub repository, upload the contents of this folder, then open repository **Settings → Pages**. Choose deployment from a branch, select `main` and `/(root)`, save, and wait for the live URL. Submit both the live website URL and repository URL.
